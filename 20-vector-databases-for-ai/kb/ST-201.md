# Staff: identity verification for card replacement

## Verification steps

Before ordering a replacement card by phone, staff must verify the caller with two factors: a one-
time code sent to the phone on file, plus one knowledge question. Never read the address on file
aloud; ask the caller to state it.

## Escalation

If verification fails twice, place a 24-hour fraud hold on the profile and transfer the call to
Fraud Operations.
