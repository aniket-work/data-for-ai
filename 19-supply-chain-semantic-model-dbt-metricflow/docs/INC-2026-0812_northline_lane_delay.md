# Incident INC-2026-0812: Northline Freight delays on Ontario lanes

From 2026-08-01 to 2026-09-15 roadwork on the main highway corridor into Toronto added about a day to some Northline Freight truckload deliveries. Northline's contracted on-time target is 95%. The delays affected loads from several suppliers, not only Pangrove. Northline added an extra driver shift on 2026-09-15.
